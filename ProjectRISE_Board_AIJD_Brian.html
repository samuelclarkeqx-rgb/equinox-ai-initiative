03 · Vaibhav's AI Proposal — Detail

SFDC Smart Alert System

The Problem

Board International does not update Salesforce frequently. Important customer info — special SLAs, triage rules, account notes — is shared via Teams and tracked in a Google Sheet. Every agent must remember to check this sheet before handling every ticket.

The Solution

  • Agent opens a case on Salesforce
  • AI automatically checks the Google Sheet for any relevant update matching the customer or issue type
  • If a match is found — a pop-up alert appears on SFDC immediately
  • Agent reads the alert and proceeds with the correct action

Examples

UNHCR case opens — AI alerts: "UNHCR is not a Premium customer despite SFDC showing otherwise. Follow non-Premium SOP."

Primark case with product issue — AI alerts: "All Primark product-related cases must be triaged to the Wipro queue."
