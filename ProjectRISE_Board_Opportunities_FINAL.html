FRT Auto-Calculate from Salesforce Phase 1
No Client IT Salesforce n8n Quick Win
▾
Problem — Confirmed by Abhinav
Agents manually enter FRT time in Google Form — and the most common mistake is entering the wrong time. This directly affects QA scores and performance data accuracy. Salesforce has the correct timestamps — but no one is using them.
AI Solution
Auto-calculate FRT directly from Salesforce ticket timestamps — ticket created time vs first response time. Auto-push to Google Sheet. No manual entry by agents ever again.
How to Achieve
  • Step 1 — Salesforce API: pull ticket creation timestamp + first response timestamp on ticket close
  • Step 2 — n8n workflow: calculate FRT automatically — flag any ticket exceeding 20 min SLA
  • Step 3 — Auto-push calculated FRT to Google Sheet via Google Sheets API
  • Step 4 — Slack alert to Abhinav for any FRT breach in real time
Client Requirement
None — Abhinav has Salesforce access. Can start immediately.

Zabbix Alert → Auto Email to Account Owner Phase 1
Board IT — One Time Zabbix n8n Quick Win
▾
Problem — Confirmed by Abhinav
When a Zabbix alert fires — memory/CPU saturation on a customer VM — agent manually creates a Salesforce ticket and then manually emails the account owner and CSM. Every step is manual and depends on the agent being available and alert.
AI Solution
Zabbix webhook → n8n → auto-create Salesforce ticket → auto-send email to account owner and CSM. Agent only follows the remediation steps — all communication is automated.
How to Achieve
  • Step 1 — Board IT enables Zabbix webhook — one-time setup — sends alert data to n8n trigger URL
  • Step 2 — n8n receives alert → parses VM name + saturation type → looks up account owner in Salesforce
  • Step 3 — Auto-creates Salesforce ticket with full alert details
  • Step 4 — Auto-sends email to account owner + CSM via email
  • Step 5 — Slack notification to team channel — entire team aware, not just one agent
Client Requirement
One-time: Board IT to enable Zabbix webhook. After setup — fully automated, no ongoing client involvement.
Feasibility Check Required
Zabbix webhook availability depends on Board's plan. Needs confirmation from Board IT before implementation.

PagerDuty AI Monitor — Auto Grafana Check Phase 2
Board IT Required PagerDuty Grafana n8n
▾
Problem — Confirmed by Abhinav
PagerDuty alert fires → agent acknowledges → follows remediation steps → waits 30 minutes → manually checks Grafana to see if saturation is reducing → decides whether to restart VM. If agent is busy with another ticket, this 30-minute window is completely unmonitored.
AI Solution
AI monitors Grafana automatically during the 30-minute wait period — sends status updates to agent every 5 minutes. If saturation is not reducing after 30 minutes — escalates to Abhinav and suggests VM restart automatically.
How to Achieve
  • Step 1 — Board IT provides PagerDuty webhook + Grafana API access
  • Step 2 — PagerDuty webhook → n8n trigger on new incident
  • Step 3 — n8n polls Grafana API every 5 minutes during incident window
  • Step 4 — If saturation reducing — Slack update to agent "Improving — continue monitoring"
  • Step 5 — If not reducing after 30 min — escalate to Abhinav + suggest restart step
Client Requirement
Board IT required — PagerDuty webhook + Grafana API access needed. Coordinate through Amy.
Feasibility Check Required
PagerDuty webhook available on Business/Enterprise plan only. Grafana API depends on whether Board uses self-hosted or cloud version. Both need confirmation from Board IT before scoping.

Robert — Auto QA Pre-Screen for Email Tickets Phase 1
No Client IT Salesforce Claude API Google Forms
▾
Problem — Confirmed
Robert manually audits every Board email ticket — reviews tone, accuracy, SOP adherence, FRT — and submits scores in Google Forms. Every ticket reviewed from scratch takes significant time. High volume means some tickets may get less thorough review.
AI Solution
Claude API pre-screens all Board email tickets automatically — flags likely fails and near-misses. Robert only reviews flagged tickets in detail. Clean tickets surface separately. Coverage increases, time saved significantly.
How to Achieve
  • Step 1 — Salesforce API: pull all closed Board email tickets daily
  • Step 2 — Claude API evaluates each ticket against QA scorecard — tone, accuracy, SOP, FRT adherence
  • Step 3 — Flagged tickets sent to Robert for review — with AI pre-assessment and suggested score
  • Step 4 — Robert reviews, adjusts if needed, submits final score to Google Forms
  • Step 5 — Pattern report generated weekly — recurring agent errors, SOP gaps identified automatically
Client Requirement
None — Salesforce access confirmed, Google Forms is Equinox's, Claude API available. Can start immediately.

No Client IT Salesforce Google Sheets n8n
▾
